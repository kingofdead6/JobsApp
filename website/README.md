# موقع التحميل — بحث عن عمل DZ

صفحة هبوط بسيطة (React + Vite + Tailwind) يحمّل منها المستخدمون التطبيق.

```bash
cd website
npm install
npm run dev      # http://localhost:5174
npm run build    # الناتج في dist/
```

---

## ⚠️ الخطوة المطلوبة منك: رابط التحميل

الموقع جاهز، لكن **رابط ملف APK فارغ حاليًا**. ما دام كذلك يعرض الموقع
زرًّا معطّلًا مكتوبًا عليه «سيتوفّر التحميل قريبًا» بدل رابط مكسور.

### 1. ارفع ملف APK

الملف موجود في:

```
mobile/build/app/outputs/flutter-apk/app-release.apk   (21 ميغابايت)
```

ارفعه إلى إحدى هذه الخدمات:

| الخدمة | الرابط المطلوب |
|---|---|
| **GitHub Releases** (مستحسن) | `https://github.com/<user>/<repo>/releases/download/v1.0.0/app-release.apk` |
| **Google Drive** | `https://drive.google.com/uc?export=download&id=<FILE_ID>` — **رابط التحميل المباشر لا رابط المعاينة** |
| أي استضافة أخرى | الرابط المباشر للملف |

> **تنبيه بخصوص Google Drive:** رابط المشاركة العادي يفتح صفحة معاينة
> ولا يحمّل الملف. استعمل صيغة `uc?export=download` أعلاه.

### 2. عدّل ملفًا واحدًا

في [`src/config.js`](src/config.js):

```js
export const APK_URL = 'https://.../app-release.apk';  // ← ضع الرابط هنا
```

يظهر زر التحميل تلقائيًا بمجرّد حفظ الملف.

### 3. عند النشر على المتاجر

في نفس الملف:

```js
export const PLAY_STORE_URL = 'https://play.google.com/store/apps/details?id=...';
export const APP_STORE_URL  = 'https://apps.apple.com/app/...';
```

تظهر أزرار المتاجر تلقائيًا، وتختفي عبارة «قيد المراجعة للنشر».

## النشر

الموقع ملفات ثابتة، يعمل على أي استضافة:

```bash
npm run build      # ثم ارفع محتوى dist/
```

- **Vercel / Netlify** — اربط المستودع واضبط:
  - Root directory: `website`
  - Build command: `npm run build`
  - Output directory: `dist`
- **GitHub Pages** — ارفع `dist/` إلى فرع `gh-pages`.

### ملاحظات تقنية

- **لا صور**: نماذج الهواتف والشعار والأيقونات كلها CSS و SVG مضمّنة،
  فلا توجد ملفات صور تُدار أو تبطئ التحميل.
- **RTL** مضبوط على مستوى `<html>`.
- **الخط**: Cairo من Google Fonts، مع بدائل نظامية إن تعذّر تحميله.
- حجم الناتج: ~54 كيلوبايت JS و~5 كيلوبايت CSS بعد الضغط.
